Updating Site Content (No Coding Required)

Everything below can be done from your web browser through the Admin area, no code editing needed.

Add or Remove a Product

  1. Log in as an admin and go to Admin → Products.
  2. Click + Add New Product, fill in the name, category, origin, price, and description, then click Save Product.
  3. After saving, add product options such as size or grind from the Options section.
  4. To remove a product, click Delete beside the product from the Products list.

Adding a New Product Photo

  1. Save your image as a .jpg or .png file.
  2. Upload the image into the assets/images/ folder using the hosting file manager or FTP.
  3. Update the product's Image Path field with the new file location and save.

Adding a New Video

  1. Export the video as an .mp4 file for better browser support.
  2. Upload the video into the assets/videos/ folder.
  3. Update the video source path on the required page or add a new video block.

Switching the Look of the Whole Site

Go to Admin → Site Template and select a theme. The website appearance will update without editing files.
